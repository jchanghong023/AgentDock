# AgentDock 只读预览示例

本文件用于手工检查 Markdown 显示。此目录不是实际业务工程。

## 工作方式

- 最近工作目录按星标、最近使用时间排列。
- 单击会话显示终端。
- 双击文件只读预览。

## 示例代码

```rust
fn main() {
    println!("Hello, AgentDock! 中文显示测试。");
}
```

| 区域 | 功能 |
| --- | --- |
| 左上 | 项目与会话 |
| 左下 | 分页系统目录树 |
| 右侧 | 原生终端或只读预览 |

> 文件浏览和预览不应改变终端进程的生命周期。
